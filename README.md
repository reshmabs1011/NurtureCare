## 📌 About the Project

NurtureCare AI is a mobile-friendly, AI-assisted maternal healthcare support platform designed to help pregnant women and community health workers access preliminary health screening, risk assessment, health information, and emergency assistance through a single web application.

The platform combines maternal health screening, a rule-based AI health assistant, health reports, emergency calling, SMS assistance, referral support, and nearby hospital discovery. It aims to improve access to maternal health support and help users connect with appropriate healthcare services when needed.

## 🎯 Project Objectives

- Provide accessible preliminary maternal health screening.
- Identify potential warning signs that may require medical attention.
- Offer a conversational assistant for common maternal health questions.
- Provide access to emergency calling and SMS communication workflows.
- Help users locate nearby hospitals.
- Support communication and referral coordination with healthcare providers.
- Provide a mobile-friendly experience for users on different devices.

## ✨ Key Features

### 🩺 1. Maternal Health Screening
Collects pregnancy-related information, such as pregnancy week, blood pressure, and reported warning symptoms, to support preliminary maternal health assessment.

### 🤖 2. AI Health Assistant
Provides rule-based responses to common maternal health questions and general guidance about warning signs, nutrition, check-ups, and healthcare support.

### ⚠️ 3. Risk Assessment and Early Warnings
Uses the project's implemented screening logic and configured machine-learning components, where applicable, to support preliminary risk assessment and highlight potential warning signs.

### 🚨 4. Emergency Calling
Provides access to India's emergency number, **112**, through a supported phone-calling workflow to help users seek urgent assistance.

### 💬 5. SMS and Referral Assistance
Helps prepare SMS messages and referral communications when users need to contact healthcare providers or other support contacts. Message delivery depends on the implemented workflow and user confirmation.

### 🏥 6. Nearby Hospital Discovery
Helps users find nearby hospitals using the location or mapping functionality available in the application.

### 📋 7. Health Reports
Displays screening records and related summaries to support review of previously recorded information.

### 📱 8. Mobile-Friendly Interface
Designed to make important maternal health support features accessible from smartphones, tablets, and desktop browsers.

## 🔄 How It Works

1. The user opens NurtureCare AI on a mobile device or computer.
2. The user enters relevant maternal health information into the screening interface.
3. The application processes the submitted information using its configured screening logic.
4. The application displays the resulting screening information and relevant warnings.
5. The user can access the health assistant, review reports, prepare referral messages, or find nearby hospitals.
6. When urgent help is required, the user can access the available emergency-calling workflow or seek other appropriate emergency assistance.

## 💻 Run the Project Locally

### Prerequisites

- Python installed on your computer
- Git installed on your computer
- A code editor such as Visual Studio Code

### Step 1: Clone the Repository

```bash
git clone https://github.com/reshmabs1011/NurtureCare.git
cd NurtureCare
```

### Step 2: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Start the Application

```bash
python app.py
```

### Step 5: Open the Website

Open this address in your browser:

```text
http://127.0.0.1:5000/
```

**Note:** Some features, such as location-based hospital discovery, phone calling, and SMS workflows, may require a compatible device, browser permissions, or additional configuration.

## ⚕️ Medical Disclaimer

NurtureCare AI is a prototype intended to support preliminary screening and healthcare communication. It is not a substitute for professional medical advice, diagnosis, or treatment. Its risk assessments and chatbot responses are not validated medical diagnoses. Anyone experiencing a possible medical emergency should seek immediate professional assistance rather than waiting for an application response.
